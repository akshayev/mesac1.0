# Glossary

| Term | Meaning |
|---|---|
| MESAC | Mechanical Engineering Students' Association (of CUSAT). "MESA" in some old text is a mistake to fix |
| CUSAT | Cochin University of Science and Technology |
| Archive | Public library of previous-year question papers and syllabi (replaces Downloads) |
| Academy | MESAC training section: six skill tracks, enrollment form, GPA calculator |
| SGPA / CGPA | Semester / cumulative grade point average |
| Scheme | Syllabus year of a course, for example "2019 Scheme" |
| HOD / Head of Division | Head of the Mechanical department |
| Academic year | For example `2026-27`; the unit for committees |
| Start new academic year | Dashboard action that archives the current team and opens a new one |
| Show contact | Per-person flag controlling whether phone/personal email is public (default off) |
| Mock data | Hardcoded sample content in `src/data/mock/` used until the backend exists |
| Service contract | TypeScript interface (in `src/types/admin.ts`) the backend must implement |
| Prototype-preview | Admin auth mode that skips real login for UI development |
| D1 / R2 | Cloudflare SQLite database / object storage |
| Turnstile | Cloudflare's invisible spam challenge |
| Nitro | Server bundler that packages the app for Cloudflare Workers |
| TanStack Start | The React meta-framework used (SSR + file routing) |
| ADR | Architecture Decision Record |
| graphify | Tool that builds a knowledge graph of the code |
| Hot-file cache | Copy of the most requested archive files on our own storage |
